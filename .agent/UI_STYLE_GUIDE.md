# PostSync 한국어 웹 조판(CSS) · 범용 UX 카피라이팅 표준

> 프론트엔드 컴포넌트 · 랜딩 페이지 · 마이크로 웹툴 UI를 작성하거나 수정할 때 적용하는 디자인 · 조판 · 문구 지침입니다.

---

## 1. 프론트엔드 CSS & 조판(타이포그래피) 6대 불변 규칙

1. **어절 단위 줄바꿈 강제 (음절 절단 금지):**
   - 모든 한국어 텍스트 컨테이너와 본문에 `word-break: keep-all;`과 `overflow-wrap: break-word;` (Tailwind: `break-keep break-words`)를 필수로 적용합니다.
   - 한글 단어 중간이 잘리는 `break-all`이나 `word-break: normal` 단독 사용을 금지합니다.
2. **제목 외톨이 단어 방지:**
   - `h1`~`h3` 제목 및 핵심 카피에는 `text-wrap: balance;`를 적용하고, 본문 문단에는 `text-wrap: pretty;`를 적용합니다.
3. **본문 최적 가독 너비:**
   - 영문 기준 `60ch` 사용을 금지합니다. 한국어 본문은 한 줄 40자 안팎이 유지되도록 `max-width: 38rem;` (또는 `40ic`) 및 `margin-inline: auto;`로 제한합니다.
4. **줄 간격(행간) · 자간 · 정렬:**
   - `line-height`는 반드시 단위 없는 숫자를 사용합니다 (본문 `1.6 ~ 1.7`, 큰 제목 `1.3`). 고정 `px` 행간 금지.
   - 본문에 음수 자간(Tailwind: `tracking-tight`) 일괄 적용을 금지합니다 (큰 제목에만 제한적 허용).
   - 양쪽 정렬(`text-align: justify`)은 절대 금지하며, 3줄 이상의 긴 본문은 왼쪽 정렬을 기본으로 합니다.
5. **반응형 높이 및 확대 접근성 (WCAG):**
   - 버튼 · 배지 · 카드 · 인풋에 고정 `height`와 `overflow: hidden`을 함께 사용하지 않습니다. 텍스트 200% 확대 시 글자가 잘리지 않도록 `min-height`와 `padding`(예: `0.5em 1em`)으로 여백을 확보합니다.
   - 전체 너비는 가로 스크롤 방지를 위해 `100vw` 대신 `100%`를 사용하고, 모바일 첫 화면 높이는 `100svh` 또는 `100dvh`를 사용합니다.
6. **폰트 스택 및 문장부호:**
   - Pretendard 동적 서브셋(WOFF2)을 기본으로 하며 `font-synthesis: none;`을 명시합니다.
   - 영문 엠대시 대신 한국어 가운뎃점(`·`)을 사용합니다.
   - WCAG AA 명도 대비(일반 텍스트 4.5:1 이상, 대형/UI 3:1 이상)를 충족하는 고대비 토큰(예: 파란 버튼 `#2563eb`)을 사용합니다.

## 2. 목적별 UX 카피라이팅 표준

1. **마이크로 웹툴 & 유틸리티 UI:**
   - **CTA/실행 버튼:** 명확한 동작 지향형 명사/기본형 동사 사용 (`[변환하기]`, `[다운로드]`, `[결과 복사]`, `[초기화]`, `[파일 선택]`). 유아적 어미(`[변환해요]`, `[다운로드해요]`) 금지.
   - **모달 보조 버튼:** 작업 전체가 취소된다는 오해를 막기 위해 `[취소]` 대신 **`[닫기]`**로 통일합니다.
   - **입력 안내(Placeholder):** 직관적 행동 안내 (`https://example.com 형식으로 입력하세요`, `변환할 텍스트를 입력하세요`).
   - **상태 · 토스트 알림:** 간결한 완료/안내형 (`변환을 완료했습니다`, `클립보드에 복사되었습니다`).
2. **웹 SaaS (대시보드 · 온보딩 · 안내):**
   - **메뉴 & 테이블 헤더:** 간결한 명사 (`상태`, `생성 일시`, `이용 내역`).
   - **온보딩 & 빈 상태(Empty State):** 친근한 주도형 해요체 허용 (`아직 생성된 작업이 없어요. 첫 번째 변환을 시작해 보세요!`).
   - **에러 · 제한 안내:** 단순 부정형 금지, 해결책 중심 긍정형 작성 (`PNG, JPG 형식만 지원합니다. 파일을 다시 확인해 주세요`).
3. **공통 어휘 정제 & Footer:**
   - `~되어집니다` 같은 이중 피동과 의미 없는 잡초 단어(`앞으로`, `혹시`)를 제거하고 능동형으로 씁니다.
   - 한국 상용 웹 Footer 필수값(상호명, 대표자명, 사업자번호, 통판번호, 고객센터, 개인정보처리방침 강조)을 누락하지 않습니다.

## 3. UI 품질 점검 체크리스트

- 금지 용어(`격차`, `타래`, `래퍼`)가 화면 카피에 포함되어 있지 않은가?
