❓ 자주 묻는 질문 (FAQ)

기밀 입찰 서류나 지원사업 신청서가 외부 서버에 유출되지 않나요?
절대 유출되지 않습니다. PostSync HWPX 안심 변환기는 JSZip과 브라우저 내장 XML DOMParser를 사용하여 100% 사용자의 PC/스마트폰 메모리 안에서만 압축을 풀고 렌더링합니다. 파일 데이터가 외부 서버로 1바이트도 전송되지 않으므로 정부 대외비나 개인정보가 포함된 문서도 안심하고 열람하실 수 있습니다.
마크다운(.md) 변환 기능은 어떤 용도로 쓰나요?
ChatGPT, Claude, Notion 등에 복사할 때 표(Table)와 소제목 서식이 그대로 유지되도록 변환해 줍니다. 긴 공공 공고문이나 지원사업 지침서를 AI에게 요약시키거나 제안서 초안을 작성하게 할 때 매우 유용합니다.
100% 브라우저 로컬 연산 및 보안 보증: 본 도구는 클라이언트 브라우저 로컬 JavaScript 엔진으로 동작하며, 업로드하신 HWPX 문서는 외부 서버로 1바이트도 전송되지 않고 사용자 기기 메모리에서만 안전하게 연산된 후 자동 소멸합니다.
