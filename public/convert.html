소제목 (H2, H3) 글자 크기가 일반 본문과 동일해져 가독성 저하 네이비 포인트 라인 & 배경 박스 인라인 스타일 자동 주입

❓ 자주 묻는 질문 (FAQ)

'네이버 블로그 서식 복사하기'는 어떤 원리로 작동하나요?
웹 브라우저 최신 클립보드 API(ClipboardItem)를 활용하여 일반 텍스트뿐 아니라 네이버 스마트에디터 ONE이 인식할 수 있는 'text/html' 데이터를 함께 생성합니다. 각 HTML 태그 내부에 인라인 CSS(style="...")를 주입하므로 네이버 에디터에 붙여넣었을 때 서식이 100% 온전하게 유지됩니다.
작성 중인 기밀 원고가 외부 서버로 저장되거나 전송되나요?
절대 전송되지 않습니다. PostSync의 모든 마이크로 웹툴은 100% 사용자의 컴퓨터 웹 브라우저 로컬 메모리상에서만 자바스크립트로 연산되므로 서버 비용이 $0이며, 어떠한 텍스트도 유출되지 않아 안심하고 사용하실 수 있습니다.
모바일 네이버 블로그 앱에서도 적용되나요?
PC 웹 브라우저에서 복사하여 모바일 스마트에디터 앱에 붙여넣어도 인라인 스타일이 유지됩니다. 다만 최적의 편집 환경을 위해 PC 환경에서 [네이버 블로그 서식 복사] 후 스마트에디터 ONE 웹 글쓰기 창에서 붙여넣는 것을 권장합니다.
100% 브라우저 로컬 연산 및 보안 보증: 본 도구는 클라이언트 브라우저 로컬 JavaScript 엔진으로 동작하며, 입력하신 데이터나 파일은 외부 서버로 1바이트도 전송되지 않고 사용자 기기 메모리에서만 안전하게 연산된 후 자동 소멸합니다.
