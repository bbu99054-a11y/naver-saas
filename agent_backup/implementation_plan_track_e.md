# 트랙 E: 데이터 대시보드 및 원고 아카이브 구현 계획서

사용자가 얼마나 많은 혜택을 누리고 있는지 시각적으로 확인하게 하고(리텐션 강화), 언제든 예전 글을 다시 볼 수 있는 저장소를 만듭니다.

## 📌 1. 대시보드 동적 데이터 연동 (`/dashboard/page.tsx`)
현재 하드코딩 되어 있는 대시보드 요약 정보를 실제 데이터 베이스와 연결합니다.
- **잔여 크레딧**: 현재 사용자의 진짜 남은 횟수를 보여줍니다.
- **이번 달 발행한 글 통계**: DB의 `Article` 테이블을 조회하여, 이번 달 1일부터 지금까지 사용자가 생성한 포스팅 개수를 계산해 뿌듯함을 줍니다.

## 📌 2. 나의 원고 저장소(Archive) 구축 (`/dashboard/archive/page.tsx`)
지금까지 AI가 대신 써준 모든 글을 영구 보관하고 재사용할 수 있는 페이지를 신설합니다.
- 좌측 사이드바에 **'나의 원고 저장소'** 메뉴 추가
- 리스트 형태로 이전에 작성했던 타겟 키워드, 생성 날짜, 제목 등을 표시.
- 특정 글을 클릭하면 저장되어 있던 순수 HTML 내용이 펼쳐지며, 바로 네이버에 원클릭으로 다시 **[복사 및 발행]** 할 수 있도록 UI를 구성합니다.

## ⚠️ User Review Required (대표님 확인 필요)

> [!IMPORTANT]
> 원고 저장소(아카이브)의 리스트 UI를 어떤 형태로 보여드릴까요?
> 
> 1. **옵션 A (테이블형)**: 엑셀처럼 날짜, 키워드, 제목이 깔끔하게 한 줄씩 나열되는 형태 (가장 많은 글을 한눈에 보기 좋음)
> 2. **옵션 B (카드형)**: 블로그 리스트처럼 네모난 카드 형태로 나열되는 형태 (시각적으로 예쁘고 썸네일을 넣기 좋음)
> 
> 데이터 관리에 익숙한 마케터 분들은 보통 **A (테이블형)**을 선호하십니다. 원하시는 방식을 선택 후 **[Proceed]** 를 눌러주시면 즉시 개발에 착수하겠습니다!
