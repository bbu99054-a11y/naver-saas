# 트랙 D: 결제 시스템 연동 및 수익화 (Monetization) 구현 계획서

가장 먼저 "돈을 버는 구조"인 결제 모듈(트랙 D)부터 완벽하게 구축하겠습니다. 사용자가 무료 제공된 크레딧을 다 소진하면 자연스럽게 결제 페이지로 유도하여 월 구독(정기 결제)을 하도록 만드는 파이프라인입니다.

## 📌 1. 요금제(Pricing) 구조 설계
매력적인 요금제 페이지(`/pricing`)를 신설하여 결제를 유도합니다.
- **Starter (월 19,000원)**: 월 30회 포스팅 (1일 1포스팅 최적화)
- **Pro (월 49,000원)**: 월 100회 포스팅 + 프리미엄 DALL-E 3 이미지 무제한
- **Agency (월 99,000원)**: 대행사용 무제한 생성

## 📌 2. 결제 대시보드 (`/dashboard/billing`)
- 사용자가 현재 남은 크레딧(포스팅 가능 횟수)을 직관적으로 확인하는 프로그레스 바 제공.
- 카드 변경, 구독 취소, 결제 내역 조회 기능 지원.

## 📌 3. 백엔드(DB & API) 연동
- **Prisma Schema 업데이트**: `User` 테이블에 결제 관련 필드(`customer_id`, `subscription_id` 등) 추가.
- **웹훅(Webhook) 처리**: 사용자가 결제를 완료하면 PG사(결제 대행사)에서 우리 서버(`/api/webhook`)로 성공 신호를 쏘고, 서버는 즉시 유저의 `credits`을 100회로 충전해주고 `plan_type`을 `PRO`로 변경합니다.

## ⚠️ User Review Required (대표님 확인 필요)

> [!IMPORTANT]
> 결제 연동을 위해 **PG사(결제 대행사)**를 결정해 주셔야 합니다.
> 
> **옵션 A: 포트원(PortOne) + 토스페이먼츠 연동 (추천 🇰🇷)**
> - 장점: 한국 자영업자들에게 가장 익숙하고 신뢰감 있는 결제 화면 제공. (네이버페이, 카카오페이 지원)
> - 단점: 사업자 등록증 등 서류 심사 과정이 다소 필요함. (테스트 환경에서는 서류 없이 바로 샌드박스 개발 가능)
> 
> **옵션 B: Stripe (글로벌 스탠다드 🌍)**
> - 장점: 개발이 압도적으로 빠르고, 강력한 구독 관리/대시보드 기능 제공. 서류 없이 즉시 도입 가능.
> - 단점: 화면이 약간 외국 서비스 같은 느낌이 날 수 있으며 한국 간편결제(네이버페이 등) 지원이 아쉬움.
> 
> 현재 단계에서는 어떤 방식(옵션 A 또는 B)으로 결제 모듈을 붙여드릴까요? 선택 후 **[Proceed]** 를 눌러주시면 바로 결제 관련 코드 개발을 시작하겠습니다!
