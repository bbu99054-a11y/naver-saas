# 내장형 사용자 가이드 구축 플랜 (고객 맞춤형)

외부 노션이나 채널톡이 아닌, **SaaS 대시보드 내부에 예쁘게 내장된(Internal) 사용자 가이드 페이지**를 구축하는 플랜입니다. 
고객이 이 SaaS를 어떻게 활용해야 "최고의 마케팅 효과(블로그 노출)"를 얻을 수 있는지, 고객 입장에서 쉽게 따라 할 수 있도록 설계합니다.

## User Review Required

> [!IMPORTANT]
> 새롭게 생성될 가이드 페이지(`/dashboard/guide`)의 목차와 내용을 아래와 같이 구성하려고 합니다. 내용이 대표님의 기획 의도와 맞는지 확인해 주세요.
> 
> **[가이드 목차 및 핵심 내용 기획]**
> **Step 1. 내 정보 관리 (AI 맞춤 학습)**
> - *내용:* "AI가 대표님만의 맞춤형 1인칭 스토리텔링 원고를 쓰기 위해서는 기본 정보가 필수입니다. 내 정보 관리 메뉴에서 직군, 상호명, 경험담 등을 상세히 적어주세요."
> 
> **Step 2. 블로그 연재 기획 (롱테일 키워드 발굴)**
> - *내용:* "막연히 '강남 행정사'라고 쓰면 상위노출이 불가능합니다. 연재 기획 메뉴에 핵심 키워드를 넣으면, 실제 고객이 검색하는 구체적인 롱테일 키워드 10개를 AI가 발굴해 줍니다."
> 
> **Step 3. SEO 블로그 쓰기 및 발행**
> - *내용:* "발굴된 키워드 옆의 '글쓰기' 버튼을 누르면 즉시 네이버 알고리즘에 최적화된 글이 생성됩니다. 생성된 HTML 복사 버튼을 눌러 네이버 스마트에디터에 붙여넣기만 하세요!"
