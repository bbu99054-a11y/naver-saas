# 사용자 가이드(CS) 링크 연동 플랜

현재 좌측 하단의 '사용 가이드' 링크가 날것의 노션(Notion) 주소로 연결되어 있어, B2B SaaS 프로덕트로서 전문성이 떨어져 보이는 문제가 있습니다.
이를 세련되고 프로페셔널하게 해결하기 위한 2가지 방법을 제안합니다.

## User Review Required

> [!IMPORTANT]
> 대표님의 비즈니스 운영 방식에 맞춰 아래 두 가지 방법 중 하나를 선택해 주세요.
> 
> **[옵션 1] 채널톡 지식백과(FAQ) 다이렉트 연동 (가장 추천 ⭐)**
> 우리가 이미 연동해 둔 '채널톡'에는 FAQ 및 가이드 문서 기능이 내장되어 있습니다. '사용 가이드' 버튼을 누르면 새 창이 뜨는 대신 **화면 우측 하단의 채널톡 메신저가 쓱 열리면서 가이드 문서들을 보여주는 방식**입니다.
> - **장점:** 고객이 화면을 벗어나지 않으며, 가이드를 보다가 모르면 바로 1:1 채팅 상담으로 넘길 수 있어 CS 효율이 극대화됩니다.
> - **조치 내용:** 버튼 클릭 시 `window.ChannelIO('showMessenger')`를 실행하도록 코드를 변경합니다.
> 
> **[옵션 2] Oopy(우피)를 활용한 노션 화이트라벨링**
> 현재 작성해두신 노션 페이지를 그대로 쓰시되, Oopy 같은 서비스를 이용해서 노션 특유의 UI를 숨기고 우리 서비스의 도메인(예: `guide.postsync.com`)으로 예쁘게 덮어씌우는 방식입니다.
> - **장점:** 대표님께서 노션에서 가이드 글만 수정하면 홈페이지처럼 실시간 반영됩니다. (스타트업에서 가장 많이 쓰는 방식)
> - **조치 내용:** 대표님께서 Oopy 셋팅 후 넘겨주시는 도메인 링크로 `layout.tsx`의 URL만 교체합니다.

## Proposed Changes (옵션 1 선택 시)

### [MODIFY] `src/app/dashboard/layout.tsx`
- 기존의 `<a href="https://notion.so">` 태그를 `<button>`으로 변경.
- `onClick` 이벤트에 채널톡 메신저를 띄우는 클라이언트 스크립트(`ChannelIO('show')`) 연동.
