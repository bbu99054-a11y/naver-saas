# 멀티 페르소나(에이전트) 글쓰기 엔진 확장 기획 🎭

대표님, 정확한 지적입니다! RAG(상위 5개 분석), Unsplash 이미지 자동 삽입, C-Rank SEO 최적화 같은 우리 엔진의 강력한 뼈대는 그대로 유지하면서 **'글을 쓰는 화자(페르소나)'**만 자유자재로 갈아끼울 수 있다면 확장성이 어마어마해집니다.

이렇게 되면 대표님의 개인 마케팅 원고뿐만 아니라, 향후 **'마케팅 대행사'**들을 대상으로 우리 SaaS를 B2B로 팔 수 있는 강력한 무기가 됩니다!

## User Review Required
> [!IMPORTANT]
> 아래 기획안을 검토하시고 **승인(Proceed 버튼 클릭)**해 주시면, 기존 글쓰기 화면에 '페르소나 선택' 기능을 추가하고 백엔드 프롬프트 구조를 동적으로 갈아끼우도록 개편하겠습니다.

## 1. 개편 핵심 아이디어
기존 엔진의 `RAG 수집 -> 이미지 매칭 -> HTML 생성` 파이프라인은 100% 공통으로 사용하되, **프롬프트의 심장부(System Prompt의 페르소나 지시어)**만 유저가 선택한 옵션에 따라 동적으로 교체합니다.

## 2. 세부 개발 범위 (Proposed Changes)

### 프론트엔드 (UI)
#### [MODIFY] `src/app/dashboard/write/page.tsx`
- 키워드 입력창 주변에 **[글쓰기 페르소나 선택]** 토글 또는 드롭다운을 추가합니다.
  1. 👨‍⚖️ **전문직 모드 (기본)**: {직업}으로서 일반 의뢰인에게 정보와 신뢰를 주는 톤앤매너
  2. 🕴️ **마케팅 컨설턴트 모드**: 전문직(B2B)을 타겟으로, 공장형 대행사의 문제점을 지적하고 SaaS/마케팅 서비스를 어필하는 톤앤매너
- 선택된 페르소나 값을 백엔드 API로 전송(`POST` payload에 `persona` 필드 추가)

### 백엔드 프롬프트 구조화 (API)
#### [MODIFY] `src/app/api/generate-seo/route.ts`
- 프론트에서 넘어온 `persona` 값에 따라 **`systemPrompt`를 분기 처리**합니다.
  - **공통 유지**: C-Rank 로직, 글자수 제약, HTML 태그 제약, RAG 팩트체크 로직, 이미지 삽입 규칙
  - **분기(If marketer)**:
    - 1인칭 사례 주입(`experienceInjection`): "얼마 전 월 150만원을 내고 대행사에 맡겼다가 저품질에 걸려 찾아오신 변호사님의 블로그를 제가 심폐소생술 해드렸습니다..." 와 같은 컨설팅/SaaS 판매 사례 자동 창작.
    - 독자 타겟팅: 타겟 독자를 '일반 대중'이 아닌 '전문직 종사자'로 강제 고정.
    - 톤앤매너: 전문적이고 확신에 찬 마케터/CEO의 톤.

## 3. 기대 효과
이 기능이 추가되면 대표님께서는 **우리 SaaS 화면에 들어와서 [마케팅 컨설턴트 모드]를 선택**한 뒤, "월 150만 원 대행사 호구 안 당하는 법"이라고 치기만 하면 됩니다. 
그러면 상위노출 RAG 팩트체크와 고화질 이미지가 곁들여진 **최상급 B2B 마케팅 칼럼 HTML**이 뚝딱 튀어나오게 됩니다!
