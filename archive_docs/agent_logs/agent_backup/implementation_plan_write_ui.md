# [블로그 쓰기 화면(Write Page) UI 개편]

원클릭 발행 버튼들이 세로로 길게 쌓여 있어 미리보기 화면이 좁아지는 문제와, 생성된 글의 제목(Title)을 명시적으로 확인하고 수정할 수 없는 문제를 해결하기 위한 UI/UX 개편 플랜입니다.

## Proposed Changes

### 1. 전용 '제목(Title)' 입력 칸 추가
미리보기 화면과 하단 발행 버튼 사이에 제목을 확인하고 수정할 수 있는 입력 칸을 추가합니다.
- **[MODIFY]** `src/app/dashboard/write/page.tsx`
  - 상태 변수 `postTitle` 추가
  - AI 생성 버튼 클릭 시, 기본 제목을 `${keyword} (SEO 최적화)` 형태로 자동 세팅
  - 렌더링 뷰어 상단(또는 하단 발행바 바로 위)에 큼직한 제목 수정용 `<Input>` 배치
  - 수정된 `postTitle`이 각각의 발행 버튼 컴포넌트로 전달되도록 Props 수정

### 2. 하단 발행 버튼 '가로 1줄 배치 (1-Row Action Bar)'
수직으로 쌓여있던 3개의 버튼 뭉치를 가로 1줄로 압축하여 공간을 확보합니다.
- **[MODIFY]** `src/components/AutoPublishBtn.tsx`
  - 네이버 아이디 입력란을 버튼 바로 위나 말풍선 툴팁(Popover) 형태로 숨기거나, 매우 얇게 1줄로 배치하여 수직 공간 절약.
- **[MODIFY]** `src/components/MultiPublishBtn.tsx`
  - 기존 세로 2줄짜리 큰 버튼(워드프레스, 티스토리)을 가로로 나란히 배치하거나, **아이콘만 있는 작은 정사각형 버튼 2개**로 변경.
- **[MODIFY]** `src/app/dashboard/write/page.tsx`
  - 하단 버튼 래퍼 컨테이너를 `flex-col`에서 `flex-row` (가로 배치)로 변경.

---

## 예상되는 UI 변화 구조

```text
[ 미리보기 뷰어 (크기가 훨씬 커짐) ]
===================================================
제목: [ 💰 자기도 모르게 떼인 세금 환급받는 법... ]  <-- 사용자가 언제든 텍스트 수정 가능
---------------------------------------------------
[네이버 복사]  [네이버 자동발행]  [W(워프)] [T(티스토리)]  <-- 1줄로 압축
===================================================
```

## User Review Required
> [!IMPORTANT]
> **버튼 디자인 선택**
> 워드프레스/티스토리 버튼을 1줄에 욱여넣으려면, 글씨를 빼고 **아이콘(로고)만 있는 정사각형 미니 버튼**으로 만드는 것이 가장 깔끔합니다. (마우스 오버 시 "워드프레스 발행" 툴팁 표시). 
> 이 방식이 괜찮으신지 확인 부탁드립니다!
