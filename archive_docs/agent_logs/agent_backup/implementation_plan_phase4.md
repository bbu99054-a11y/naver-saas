# Phase 4: 사진 업로드 및 작성 유연성 강화 (UX 고도화)

안녕하세요 대표님! 2026년식 최신 기능들을 기반으로 잊지 않고 잘 오셨습니다. 요청하신 두 가지 개선 사항을 완벽하게 구현하기 위한 개발 플랜을 준비했습니다.

## 🎯 목표 (Goal)
1. '핵심 상담 사례(경험담)' 입력을 필수가 아닌 **선택(Optional)**으로 변경하여 작성을 유연하게 합니다.
2. 사용자가 직접 찍은 **실사 사진(현장 사진, 자료 등)을 업로드**하면, AI가 글 문맥에 맞춰 해당 사진들을 본문 중간중간에 자동 삽입하도록 합니다.

---

## ⚠️ User Review Required (중요 확인 사항)
> [!IMPORTANT]
> 사용자가 업로드한 이미지는 네이버 블로그 등에 발행되기 전까지 인터넷에 공개되어야 AI가 HTML에 넣을 수 있습니다.
> 이를 위해 우리가 사용 중인 데이터베이스(Supabase)의 **Storage(파일 저장소)** 기능을 사용해야 합니다.
> 
> **진행을 위해 대표님께서 Supabase 대시보드에서 다음 작업을 해주셔야 합니다:**
> 1. Supabase 대시보드 -> Storage 메뉴 이동
> 2. `blog-images` 라는 이름으로 새 Bucket(버킷) 생성
> 3. 버킷 설정에서 **"Public bucket"**을 반드시 체크하여 누구나 이미지를 볼 수 있게 설정

---

## 🛠️ Proposed Changes (변경 예정 사항)

### 1. API 로직 개편 (백엔드)
#### [MODIFY] `src/app/api/generate-seo/route.ts`
- **선택적 경험담 처리**: `experience` 파라미터가 없어도 에러를 뱉지 않도록 수정하고, 값이 있을 때만 프롬프트에 주입합니다.
- **이미지 URL 주입**: 클라이언트에서 업로드한 이미지 URL 목록(`imageUrls`)을 받아, AI에게 "AI 생성 이미지 대신 사용자가 제공한 실제 이미지 URL 리스트를 문맥에 맞게 HTML `<img>` 태그로 삽입하라"고 지시합니다.

### 2. UI 및 업로드 로직 개편 (프론트엔드)
#### [MODIFY] `src/app/dashboard/write/page.tsx`
- **UI 변경**: '핵심 상담 사례 1줄' 라벨을 `(필수)`에서 `(선택)`으로 변경합니다.
- **이미지 업로드 컴포넌트 추가**: 키워드 입력란 아래에 `[사진 첨부 (최대 3장)]` 버튼을 추가합니다.
- **업로드 로직 (Supabase Storage)**: 'AI 블로그 생성하기' 버튼을 누르면, 먼저 첨부된 사진들을 Supabase의 `blog-images` 버킷에 업로드하여 Public URL을 받아옵니다.
- **API 호출**: 받아온 이미지 URL 배열을 `/api/generate-seo` 호출 시 함께 전송합니다.

## 🧪 Verification Plan (검증 계획)
- **Manual Verification**: 
  1. 경험담을 비워두고 키워드만 입력해도 블로그가 잘 생성되는지 확인합니다.
  2. 실제 사진 2장을 첨부하고 글을 생성했을 때, 생성된 HTML 미리보기 화면에 내가 올린 사진이 깨지지 않고 잘 노출되는지 확인합니다.

> [!TIP]
> **오픈 퀘스천**:
> Supabase Storage 버킷(`blog-images`) 생성이 혹시 번거로우시다면, 제가 이 작업을 대신할 자동화 스크립트를 짜거나 브라우저에서 텍스트로(Base64) 변환해서 넘기는 임시 방편을 쓸 수도 있습니다. (하지만 속도와 안정성을 위해 가급적 Supabase Bucket 생성을 추천드립니다!)
