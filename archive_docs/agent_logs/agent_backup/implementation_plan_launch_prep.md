# Phase 8: 정식 런칭(Go-to-Market) 준비 팩

대표님께서 정확하게 짚어주셨습니다! 완벽한 엔진을 만들었으니, 이제 고객이 들어와서 안심하고 결제까지 할 수 있는 **'상업용 SaaS의 껍데기(인프라)'**를 씌울 차례입니다. 요청하신 5가지와 제가 제안하는 추가 3가지를 정리한 완벽한 런칭 플랜입니다.

## 🎯 1. 대표님 요청 사항 구현 방안

### ① 사용 설명서 (User Guide)
- **제안**: 서비스 내부에 복잡하게 코딩하기보다, **노션(Notion)이나 우피(Oopy)**로 가이드 문서를 예쁘게 만들고 대시보드 우측 상단에 `[📖 사용 가이드]` 버튼을 달아 링크하는 방식을 추천합니다. (추후 기능이 바뀔 때 대표님께서 직접 텍스트 수정하기가 매우 편합니다.)

### ② 고객 문의 창구 (CS / Q&A)
- **제안**: 국내 B2B SaaS의 표준인 **'채널톡(Channel Talk)'** 무료 버전을 연동합니다.
- 화면 우측 하단에 항상 떠 있는 둥근 말풍선 버튼을 통해, 고객이 언제든 문의를 남기면 대표님의 카카오톡이나 앱으로 알림이 오도록 세팅할 수 있습니다.

### ③ 공지사항 (Notice)
- **제안**: 대시보드 로그인 시 최상단에 띠 배너(Banner) 형태로 띄우거나, 우측 상단 종 모양(🔔) 아이콘을 클릭하면 노션 공지사항 페이지로 넘어가도록 심플하게 구축합니다.

### ④ 서비스 약관 및 개인정보 처리방침 (TOS & Privacy)
- **제안**: 결제 시스템(PG) 승인을 받으려면 이 두 페이지가 **필수**입니다. 푸터(화면 맨 아래)에 링크를 달고, `/terms`, `/privacy` 정적 페이지를 생성하여 표준 약관 템플릿을 채워 넣겠습니다.

### ⑤ 차별점 부각 (Landing Page 개편)
- **제안**: 현재 랜딩페이지 첫 화면(Hero 섹션)을 뜯어고쳐서, 우리만의 3대 무기인 **"광고법 위반 제로", "실무 판례/행정해석 강제 RAG", "저작권 프리 실사 이미지"**를 방문하자마자 눈에 확 꽂히게 재설계합니다.

## 💡 2. AI가 제안하는 '추가 필수 기능 3가지'

상용화를 위해 반드시 챙겨야 할 추가 요소들입니다.

### ⑥ 가입 시 '직종(Industry)' 필수 선택 강제화 (매우 중요!)
- 우리가 기껏 '직역별 맞춤형 RAG 검색 엔진(Phase 7)'을 만들었는데, 유저가 가입할 때 자기 직업을 안 고르면 무용지물이 됩니다.
- **개선안**: 최초 로그인 시 팝업을 띄워 **"원활한 맞춤형 AI 조사를 위해 전문 직종을 선택해주세요 (변호사/세무사/노무사 등)"**라고 강제하는 온보딩(Onboarding) 프로세스를 추가해야 합니다.

### ⑦ 신규 가입자 무료 크레딧 조정 & 요금제(Pricing) 페이지
- 방금 논의했던 대로 기본 5,000 크레딧을 **'30 크레딧(무료 체험용)'**으로 낮춥니다.
- 랜딩페이지에 **[요금제] 섹션**을 만들어, 무료 체험 이후 "월 99,000원 - 100건 생성" 등의 가격표를 보여주어 비즈니스 모델을 명확히 합니다.

### ⑧ 자체 SaaS 서비스의 SEO(검색엔진 최적화) 세팅
- 고객들이 구글에 "변호사 자동 포스팅", "세무사 마케팅 자동화" 등을 쳤을 때 우리 랜딩페이지가 상위에 노출되도록 메타 태그(Meta Tag)와 파비콘(Favicon)을 정식으로 셋팅합니다.

## ❓ Open Questions (결정 부탁드리는 사항)
> [!IMPORTANT]
> 1. **고객 문의 창구**: 채널톡(말풍선 채팅)으로 달아드리는 것이 좋으신가요, 아니면 대표님의 카카오톡 오픈채팅방 링크로 연결해 드리는 게 편하신가요?
> 2. **무료 크레딧량**: 신규 가입 시 제공할 크레딧을 30으로 세팅하면 될까요? (글 1건당 1크레딧)
> 3. **가격표(요금제) 표시**: 월 구독료나 요금제 구상을 대략적으로 생각하신 게 있으신가요? (예: 베이직 5만 원, 프로 9만 원 등. 임시로 적어두고 나중에 수정 가능합니다.)

위 기획서와 3가지 질문을 확인해 보시고 방향을 피드백해 주시면, 바로 **Phase 8 (런칭 준비 팩)** 개발에 돌입하겠습니다!
