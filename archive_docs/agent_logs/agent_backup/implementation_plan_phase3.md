# Phase 3: 전문직 특화 RAG 고도화 및 UX 개선 계획서

대표님이 짚어주신 5가지 포인트는 2026년 AI SaaS 시장의 핵심을 찌르는 완벽한 피드백입니다. 소상공인을 넘어 지불 여력이 훨씬 큰 **고소득 전문직(변호사, 세무사, 의사 등)**으로 타겟을 확장하고, 맞춤형 RAG를 적용하여 서비스의 퀄리티를 한 차원 더 끌어올리겠습니다.

## 📌 1. 내 정보 관리 및 RAG 지식베이스 (`/dashboard/settings/profile`)
가게 이전이나 업종 변경 시 언제든 정보를 수정할 수 있는 페이지를 신설합니다.
- **기본 정보 수정**: 업체명, 주소, 연락처, 예약 링크 수정 기능.
- **[핵심] 커스텀 RAG 지식베이스 입력란**: '우리 업체만의 전문성, 승소 사례, 브랜드 철학' 등을 자유롭게 텍스트로 적어두거나 복사해서 붙여넣을 수 있는 대형 텍스트 영역(`about_us` 필드)을 DB에 추가합니다.
- **RAG 동작 방식**: AI가 글을 쓸 때, 이 지식베이스를 최우선으로 읽어들여 뻔한 AI 글이 아닌 '전문가의 실제 사례와 철학이 담긴 칼럼'을 작성하게 됩니다.

## 📌 2. 고소득 전문직 타겟 랜딩페이지 리뉴얼 (`/`)
- 기존 '소상공인' 위주의 카피라이팅을 **"전문직(변호사/세무사/병원)을 위한 AI 블로그 마케팅 자동화"**로 확장 및 고급화합니다.
- **로그인 전 동작 데모 추가**: 랜딩페이지 중간에 1) 키워드 입력 ➡️ 2) 내 RAG 지식 기반 AI 칼럼 작성 ➡️ 3) 네이버/워드프레스 동시 발행 의 3단계 프로세스를 보여주는 **시각적 데모 UI(애니메이션)**를 추가하여 신뢰도를 높입니다.

## 📌 3. 2026 트렌드 기타 추가 기능 제안: 내부 링크 자동화(Internal Linking)
2026년 검색엔진 SEO의 핵심 트렌드인 **'주제 권위(Topical Authority)'**를 달성하기 위한 기능을 추가합니다.
- AI가 새 글을 쓸 때, **내 아카이브(저장소)에 있는 이전 글 중 관련 있는 글을 1~2개 자동으로 찾아내어 본문 중간에 "관련 칼럼: [이전 글 제목](링크)" 형태로 삽입**해 줍니다. 
- 이 기능은 네이버나 워드프레스의 체류 시간을 극단적으로 늘려주어 검색 상위 노출에 엄청난 가산점을 줍니다.
