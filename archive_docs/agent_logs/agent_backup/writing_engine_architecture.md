# ExpertSEO AI 글쓰기 엔진(Writing Engine) 아키텍처 진단서

이 문서는 현재 `ExpertSEO AI` 시스템의 핵심 코어인 **블로그 원고 자동 생성 엔진 (`/api/generate-seo/route.ts`)**의 작동 원리와 프롬프트 엔지니어링 구조를 상세히 정리한 문서입니다. 다른 LLM(ChatGPT, Claude 등)에게 본 문서를 복사하여 전달하시면, 현재 엔진의 수준을 진단받거나 개선점을 도출하는 데 큰 도움이 됩니다.

---

## 1. 엔진 개요 및 파이프라인 (Pipeline)
본 엔진은 단순히 LLM에게 키워드를 던져주고 글을 받는 형태가 아닙니다. **실시간 검색(RAG) + 사용자 지식(RAG) + 네이버 상위 노출(SERP) 분석 + 다이내믹 템플릿**을 결합한 7단계 하이브리드 파이프라인을 거칩니다.

1. **병렬 데이터 로드**: 유저 크레딧, 프로필 정보(RAG 지식), 과거 작성 원고 2개(내부 링크용)를 `Promise.all`로 동시 조회하여 지연 시간을 최소화합니다.
2. **실시간 SERP 분석**: 타겟 키워드로 네이버 블로그 상위 노출 5개 문서를 실시간 분석하여 적정 글자 수, 이미지 수, 필수 목차(H2) 구조를 추출합니다.
3. **Tavily 웹 검색 (RAG)**: 타겟 키워드와 관련된 최신 뉴스, 판례, 트렌드를 실시간 검색하여 팩트 기반의 컨텍스트를 확보합니다.
4. **다중 프롬프트 인젝션 (Multi-Prompt Injection)**: 6개의 각기 다른 목적을 가진 모듈형 프롬프트를 조합하여 하나의 강력한 시스템 프롬프트를 완성합니다.
5. **멀티 LLM 라우팅**: 사용자가 선택한 모델(Claude, GPT, Gemini)로 Vercel AI SDK의 `streamText`를 호출합니다.
6. **순수 HTML 렌더링**: 마크다운을 거치지 않고, 네이버 스마트에디터에 100% 호환되는 인라인 CSS 기반의 순수 HTML을 실시간 스트리밍으로 뱉어냅니다.
7. **Post-Action**: 생성이 완료되면 크레딧을 삭감하고 DB(`Article` 테이블)에 저장합니다.

## 2. 프롬프트 인젝션 모듈 (Prompt Injection Modules)
시스템 프롬프트는 6개의 독립적인 모듈로 주입(Injection)됩니다.

### ① RAG Injection (전문성/페르소나 부여)
- **목적**: 기계적인 글을 방지하고, 해당 전문직(사용자)의 철학과 이력이 담긴 진짜 글을 만들기 위함.
- **내용**: 사용자가 사전 입력한 `about_us` 데이터를 최우선 지식베이스로 주입하여, "전문가가 직접 자신의 노하우를 풀어낸 글"로 톤앤매너를 고정시킵니다.

### ② Experience Injection (D.I.A.+ 독창성 알고리즘 대응)
- **목적**: 네이버 D.I.A.+ 알고리즘이 요구하는 '경험 기반의 독창적 문서' 점수를 확보하기 위함.
- **내용**: 사용자가 입력한 '오늘의 핵심 상담 사례 1줄'을 글의 서론/본론에 자연스럽게 녹여내도록 강제합니다. (현재 선택 사항으로 유연하게 동작)

### ③ Context Injection (C-Rank 알고리즘 대응)
- **목적**: 타겟 키워드의 네이버 상위 노출 블로그들의 평균적인 문서 규격을 맞추기 위함.
- **내용**: 실시간 크롤링된 권장 글자 수, 이미지 개수, 상위 블로거들이 자주 쓰는 목차(H2) 리스트를 프롬프트에 주입하여 문서 구조의 뼈대를 잡습니다.

### ④ Internal Link Injection (SEO 2026 트렌드)
- **목적**: 블로그 체류 시간을 늘리고 주제 권위(Topical Authority)를 확보하기 위함.
- **내용**: DB에서 사용자가 과거에 쓴 글의 제목 2개를 가져와, 본문 중간에 자연스럽게 `<a>` 태그(하이퍼링크)를 이용해 '함께 읽으면 좋은 글' 형태로 삽입하도록 지시합니다.

### ⑤ Design & Template Injection (가독성 및 시각화)
- **목적**: 텍스트 중심의 밋밋한 '워드 문서' 형태를 탈피하고 트렌디한 블로그 레이아웃을 구성하기 위함.
- **내용**: 본문 텍스트 중앙 정렬, 줄 간격(line-height: 2.0), 형광펜 하이라이트 효과, 이모지 적극 사용 지시를 내립니다. 또한 인포박스, 인용구 등의 미리 짜여진 HTML/CSS 템플릿 코드를 주입하여 텍스트만 갈아끼우도록 통제합니다.

### ⑥ Footer CTA Injection (전환율 극대화)
- **목적**: 포스팅을 읽은 잠재 고객이 실제 예약이나 전화 문의로 이어지게 함.
- **내용**: 사무소 이름, 전문 분야, 주소, 전화번호, 예약 링크를 글의 최하단에 항상 박스 형태로 깔끔하게 덧붙이도록 강제합니다.

## 3. 시각 자료(이미지) 자동화 처리
- **방식**: 외부 프롬프트형 AI 이미지 생성기인 `Pollinations AI`를 사용합니다.
- **로직**: 프롬프트 제약사항에 `<img src="https://image.pollinations.ai/prompt/{장면에_맞는_영문_프롬프트}?width=800&height=600&nologo=true" style="...">` 형태의 정규화된 태그를 삽입하라고 명령합니다. AI가 문맥에 맞는 영문 프롬프트를 동적으로 생성해 URL에 삽입하므로, 글이 생성될 때 이미지가 실시간으로 불러와집니다.

---

## 4. 제약 사항 (Constraints)
- HTML 최상위 래퍼 태그(`<html>`, `<body>`) 및 마크다운 코드블록(```html) 사용 엄격 금지. (스마트에디터 복사 시 깨짐 방지)
- 블로그 제목은 별도로 입력하므로 본문 내 `<h1>` 태그 사용 금지 (오직 `<h2>`, `<h3>`만 허용).
- 서론 작성 시 APB(문제 제기 - 해결책 제시 - 브릿지) 프레임워크를 의무 사용하여 7초 내 이탈 방지.
- Tavily로 검색된 실제 팩트 기반 데이터와 출처를 본문에 자연스럽게 표기.
