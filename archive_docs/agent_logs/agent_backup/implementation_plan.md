# 2026년 기준 모델명 롤백 및 에러 원인 추적(디버깅) 강화 계획

대표님, 제가 연도를 착각하고(환각) 임의로 코드를 수정한 점 진심으로 사과드립니다. 
2026년 최신 모델명(`gemini-3.6-flash`, `gpt-5.6-luna`, `claude-5-sonnet-latest`)이 맞으며, 이를 다시 원상 복구(Rollback) 하겠습니다.

다만, 원상 복구 후에도 Vercel 서버에서 계속 **글 생성이 안 되고 키워드 3개가 안 나오는 현상**이 유지될 수 있습니다. (예: Vercel 환경 변수에 API 키가 누락되었거나, 통신 타임아웃 등)

따라서 이번 수정에서는 **모델명을 2026년형으로 롤백함과 동시에, 서버 내부에서 숨겨져 있던 에러 메시지를 화면에 직접 띄워주는(디버깅) 기능을 추가**하여 승인을 요청합니다.

## User Review Required
> [!IMPORTANT]
> 본 수정안은 Vercel 서버 내부에서 조용히 무시되고 있던 에러를 대시보드 화면에 직접 출력하여 정확한 원인을 파악하기 위한 목적이 포함되어 있습니다. 내용을 확인하시고 승인(Proceed)해 주시면 즉시 코드를 반영하겠습니다.

## Proposed Changes

### 1. `src/actions/curation.ts`
- **[MODIFY]**: 제가 임의로 수정했던 2024년형 모델명을 다시 2026년형(`gemini-3.6-flash`, `gpt-5.6-luna`)으로 원상 복구합니다.
- **[MODIFY]**: 에러 발생 시 빈 배열(`[]`)만 넘겨주어 화면에 아무것도 안 뜨던 현상을 개선하기 위해, 반환 타입을 `{ clusters: Array, error: string }` 구조로 변경하여 정확한 에러 원인을 반환합니다.

### 2. `src/app/api/generate-seo/route.ts`
- **[MODIFY]**: 모델명을 `claude-5-sonnet-latest` 등 2026년형으로 원상 복구합니다.
- **[MODIFY]**: 에러 반환 시 단순히 "서버 에러가 발생했습니다" 대신, 500 에러의 실제 원인(예: `error.message` 또는 `error.toString()`)을 함께 클라이언트로 응답하도록 개선합니다.

### 3. `src/app/dashboard/DashboardCuration.tsx`
- **[MODIFY]**: `curation.ts`에서 에러 메시지가 넘어오면 화면을 숨기는(`return null`) 대신, 붉은색 경고 박스로 **"키워드 분석 실패 사유: [실제 에러 내용]"** 을 대시보드에 직접 출력하여 대표님께서 원인을 바로 인지하실 수 있도록 수정합니다.

## Verification Plan
1. 위 변경 사항을 적용하고 GitHub에 푸시(Push)합니다.
2. Vercel에 자동 재배포가 완료되면, 대표님께서 대시보드에 접속합니다.
3. 만약 API 키 누락이나 통신 문제가 있다면 **대시보드 화면에 정확한 에러 사유가 출력**될 것이며, 문제가 없다면 정상적으로 3개의 키워드가 다시 나타날 것입니다.
