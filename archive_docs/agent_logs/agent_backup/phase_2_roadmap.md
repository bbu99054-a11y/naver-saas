# 🚀 Phase 2 (고도화 단계) 로드맵 제안

성공적으로 Vercel 글로벌 서버에 배포된 MVP(1차 완성본)를 기반으로, 이제 본격적인 수익 창출과 서비스 자동화를 극대화하기 위한 **Phase 2 고도화 작업**을 시작할 차례입니다.

대표님의 비즈니스 방향성에 맞춰 아래 3가지 트랙 중 가장 먼저 도입하고 싶은 기능을 선택해 주세요.

---

## 🟢 트랙 A: '완전 자동화' 및 '수익화' 파이프라인 (추천)
> 블로그를 통한 제휴 마케팅 수익을 극대화하는 기능입니다.

1. **쿠팡 파트너스 API 자동 연동**
   - 현재 설정 페이지에 저장해 둔 API 키를 활용하여, AI가 글을 쓸 때 **자연스럽게 쿠팡 파트너스 상품 링크와 수익화 배너를 자동 삽입**하는 기능입니다.
2. **워드프레스(WordPress) 자동 포스팅 연동**
   - 크롬 익스텐션을 통한 네이버 블로그 수동 발행 외에도, 워드프레스 블로그에는 버튼 하나로(또는 예약 설정으로) **API를 통해 원격 자동 발행**하는 기능을 활성화합니다.

## 🔵 트랙 B: AI 퀄리티 초격차 (콘텐츠 고도화)
> 사람이 쓴 것과 구별할 수 없는 최고 품질의 글과 이미지를 만듭니다.

1. **AI 이미지 자동 생성 및 삽입 (DALL-E 3 / Stable Diffusion)**
   - 글만 있는 밋밋한 포스팅 대신, 글 내용에 맞는 고품질 썸네일과 본문 이미지를 AI가 알아서 그려서 중간중간 삽입해 줍니다.
2. **외부 링크(출처) 및 최신 뉴스 웹 검색 통합**
   - 2026년 최신 트렌드를 반영하기 위해, AI가 글을 쓰기 전 실시간으로 구글/네이버 뉴스를 검색하고 실제 팩트 기반의 출처 링크를 글 안에 인용합니다.

## 🟣 트랙 C: SaaS 유료 결제 시스템 구축
> 이 시스템을 다른 사람(고객)에게 팔아서 구독료를 받습니다.

1. **Stripe / 포트원(Portone) 결제 연동**
   - 월 29,000원 등의 요금제를 만들고, 사용자들이 카드로 결제해야만 AI 글쓰기 기능을 사용할 수 있도록 권한 시스템(크레딧 차감 기능)을 도입합니다.
2. **어드민(관리자) 대시보드**
   - 전체 가입자 수, 결제 현황, 유저들이 생성한 키워드 통계를 한눈에 볼 수 있는 관리자 전용 페이지를 구축합니다.
