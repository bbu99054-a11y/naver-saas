# 인텐트(검색 의도) 기반 진짜 롱테일 키워드 개선 플랜

현재 AI가 '강남 법인설립 대행', '삼성역 행정사'처럼 단순한 2~3어절의 뻔한 키워드만 뱉어내는 이유는, **이전에 네이버 광고 API 에러를 피하기 위해 강제로 걸어두었던 '글자수 제한(15자 이내) 및 명사형 조합 제약'** 때문입니다.

이제 네이버 API 의존성을 완전히 제거했으므로, 굳이 짧은 단어에 집착할 필요가 없습니다. 고객이 진짜 궁금해하는 구체적인 상황(Scenario)과 질문(Question)형 롱테일 키워드를 뽑아내도록 프롬프트를 전면 개편하는 플랜을 제안합니다.

## User Review Required

> [!IMPORTANT]
> 프롬프트를 아래와 같이 변경하면, 단순 명사 조합이 아닌 **"구체적인 문제 상황이나 질문형태"** 의 매우 디테일한 키워드들이 생성됩니다. 
> 예: `단순 키워드(강남구 행정사)` -> `실제 롱테일(음주운전 구제 행정심판 기각 시 재심 청구 방법)`
> 이러한 형태로 도출되는 것이 대표님이 원하시는 방향과 일치하는지 확인 부탁드립니다.

## Proposed Changes

### 1. AI 프롬프트 제약조건 전면 해제 및 재설계
기존의 길이 제한을 풀고, 고객의 'Pain Point(고충)'를 직접적으로 건드리는 인텐트 기반 키워드를 생성하도록 지시합니다.

#### [MODIFY] `src/actions/curation.ts` (대시보드 메인 추천 키워드용)
#### [MODIFY] `src/app/api/generate-clusters/route.ts` (블로그 연재 기획기용)

**[프롬프트 변경 핵심 내용]**
- **기존 제한 삭제:** "문장형 키워드 금지", "15자 이내", "2~3어절 명사 조합" 제한을 모두 삭제합니다.
- **새로운 생성 규칙 추가:**
  1. **구체적 상황 부여:** "단순 명사 나열이 아닌, 고객이 실제로 처한 구체적인 문제 상황이나 질문을 반영한 롱테일 키워드를 작성하세요."
  2. **의도 세분화:** "정보 탐색형(예: E-7 비자 발급 조건), 문제 해결형(예: 영업정지 구제 행정심판 비용), 전환형(예: 강남구 법인설립 대행 수임료) 키워드를 골고루 섞어서 10개를 구성하세요."
  3. **예시 제공:** `(X) 강남 행정사 -> (O) 강남 식당 미성년자 주류 판매 영업정지 구제 방법`
