# 요금제 기반 AI 모델 자동 매핑 완료 (Walkthrough)

고객이 직접 AI 모델을 골라야 했던 피로감(UX 저하)을 없애고, 무료 회원이 비싼 모델을 남용하는 비용 누수(수익화 실패)를 막기 위해 **모델 선택 기능을 전면 폐지하고 요금제 자동 매핑 시스템을 도입**했습니다.

## 🚀 주요 개선 사항

### 1. 사용자 화면(UI) 간소화 및 업셀링(Upselling) 강화
- **글쓰기 페이지** 및 **연재 기획 페이지**에 있던 복잡한 'AI 모델 선택' 드롭다운을 완전히 삭제했습니다. 이제 고객은 키워드만 넣고 버튼만 누르면 됩니다.
- 대신, 기존 선택창 위치에 **[최고 품질의 Claude 5 모델을 사용하시려면 Pro로 업그레이드 하세요!]** 라는 유도 배지(Badge)를 달아 결제 전환율(CVR)을 높일 수 있도록 구성했습니다.

### 2. 백엔드(API) 강제 라우팅 적용
클라이언트(브라우저)에서 넘겨주던 모델 데이터는 더 이상 신뢰하지 않으며, 서버 API단에서 데이터베이스를 직접 조회하여 유저의 `plan_type`에 따라 모델을 배정합니다.
- `plan_type`이 **Pro** 또는 **Premium**인 경우: 현존 최고 성능의 `Claude 5 Sonnet` 배정
- `plan_type`이 **Free**인 경우: 빠르고 가성비가 훌륭한 `Gemini 3.6 Flash` 배정

### 3. 무결점 Vercel 배포 완료
이번 작업으로 인해 `src/app/api/generate-seo/route.ts` 등 총 4개의 핵심 파일이 수정되었으며, `AGENTS.md` 제약사항에 따라 배포 전 타입스크립트 에러 검증(`tsc --noEmit`)을 100% 통과했습니다.
