# 트랙 B: AI 퀄리티 초격차 구현 계획서 (수정본)

대표님의 피드백을 완벽하게 반영하여, 웹 검색은 **Tavily API**를 사용하고 이미지 생성은 개발/수정 단계에 맞춰 **완전 무료 서비스**를 연동하는 방향으로 플랜을 업데이트했습니다.

## 📌 주요 목표 및 확정된 솔루션

### 1. 실시간 뉴스/웹 검색 연동 (Tavily API)
- **선택 사유**: AI 특화 검색 엔진인 Tavily를 사용하여 구글/네이버 뉴스보다 훨씬 정제된 최신 팩트와 출처를 가져옵니다.
- **구현 방식**: `streamText` 내부 도구(Tool)로 `search_news`를 만들고, Tavily API를 호출합니다.
- **사전 준비**: 무료 티어(월 1,000건) 가입 후 `TAVILY_API_KEY`를 Vercel 환경 변수에 추가해야 합니다.

### 2. 완전 무료 고품질 이미지 자동 생성 (Pollinations AI)
- **선택 사유**: 2026년 기준, 별도의 API 키 발급조차 필요 없고 요금도 전혀 발생하지 않는 오픈소스 기반 완전 무료 서비스(Pollinations.ai / SD3 기반)를 활용합니다. 개발/수정 단계에서 무제한으로 퀄리티를 테스트해 볼 수 있습니다.
- **구현 방식**: AI가 문맥에 맞는 프롬프트를 영어로 번역하여 `https://image.pollinations.ai/prompt/{프롬프트}` 형태의 무료 API를 호출하도록 설계합니다. 이렇게 만들어진 이미지를 HTML 본문 중간에 `<img>` 태그로 2장 삽입합니다.
