# 글쓰기 생성 에러 해결 완료 (Walkthrough)

이전 온보딩 페이지에서 발생했던 문제와 동일한 **'Supabase PgBouncer 트랜잭션 충돌 버그'** 가 글쓰기 API 쪽에도 웅크리고 있던 것을 발견하여 말끔히 치료했습니다.

## 🚀 주요 개선 사항

### 1. 글쓰기(AI 원고 생성) API 안정화
롱테일 키워드 목록에서 `[바로 글쓰기]`를 눌러 넘어간 뒤, 원고 생성을 시작할 때 **유저의 크레딧 정보를 업데이트하는 과정에서 발생하던 데이터베이스 에러**를 해결했습니다.
- 원인: `prisma.user.upsert` (단일 트랜잭션 충돌)
- 해결: `prisma.user.findUnique` 후 조건부 `create/update` 로직으로 우회 처리.

### 2. 환경설정(API Key 저장) 잠재적 버그 사전 차단
프로젝트 전체를 샅샅이 뒤져본 결과, 나중에 외부 API 연동 키를 저장하실 때 동작하는 `src/actions/settings.ts` 안에도 동일한 `upsert` 버그가 도사리고 있었습니다.
- 에러가 터지기 전에 **미리 선제적으로 해당 로직을 모두 분해하여 안전한 코드로 교체**했습니다. 

---

> [!TIP]
> 배포 전 `tsc --noEmit` 에러 검증을 100% 통과했습니다. 현재 Vercel에서 실서버 배포 중이며, 잠시 후 다시 `[글쓰기 시작]` 버튼을 누르시면 정상적으로 AI 원고가 콸콸콸 쏟아져 나오는 모습을 보실 수 있습니다!
