# 트랙 F: 타 플랫폼(워드프레스 / 티스토리) 동시 발행 자동화 구현 계획서

네이버 블로그를 넘어, 작성된 고품질 AI 원고를 **워드프레스**와 **티스토리**에도 클릭 한 번으로 동시 발행할 수 있는 기능을 구축합니다.

## 📌 1. 데이터베이스 스키마 확장 (`schema.prisma`)
워드프레스와 티스토리 발행에 필요한 인증 정보를 저장하기 위해 `ApiKey` 모델을 확장합니다.
- `wp_url`: 워드프레스 사이트 주소
- `wp_username`: 워드프레스 사용자명
- `tistory_access_token`: 티스토리 OpenAPI 토큰
- `tistory_blog_name`: 티스토리 블로그 이름

## 📌 2. API 설정 페이지 고도화 (`/dashboard/settings`)
확장된 DB에 맞춰, 사용자가 워드프레스 주소/계정 정보와 티스토리 연동 정보를 입력할 수 있는 UI를 추가합니다.

## 📌 3. 플랫폼별 자동 발행 API 구축
원고 데이터를 전달받아 각 플랫폼의 API 규격에 맞춰 전송(POST)하는 서버 백엔드를 구축합니다.
- `/api/publish/wordpress`: WP REST API(`wp-json/wp/v2/posts`)를 사용하여 Basic Auth로 발행.
- `/api/publish/tistory`: Tistory OpenAPI(`/apis/post/write`)를 사용하여 발행.

## 📌 4. 아카이브 및 원고 상세 페이지 UI 추가 (`/dashboard/archive/[id]`)
기존의 '네이버 복사' 버튼 아래에 새로운 액션 버튼들을 추가합니다.
- **[🚀 워드프레스에 원클릭 발행]** 버튼 추가
- **[🚀 티스토리에 원클릭 발행]** 버튼 추가
- 버튼 클릭 시 로딩 스피너와 함께 백엔드 API를 호출하여 즉시 해당 블로그에 포스팅이 완료되도록 연동합니다.

> [!IMPORTANT]
> 티스토리(Tistory) API 연동 방식에 대해 확인이 필요합니다.
