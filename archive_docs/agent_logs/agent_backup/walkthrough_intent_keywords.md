# 인텐트 기반 진짜 롱테일 키워드 개선 완료 (Walkthrough)

과거 네이버 API 에러를 회피하기 위해 억지로 걸어두었던 AI 프롬프트 제약 조건(길이 제한, 단어 수 제한)을 완전히 해제하고, 고객의 실제 고충(Pain Point)과 검색 의도(Intent)를 반영하도록 백엔드 로직을 전면 수정했습니다.

## 🚀 주요 개선 사항

### 1. 단순 명사 나열 금지 및 "질문/상황형" 키워드 유도
기존 `(X) 강남 행정사` 같이 포괄적이고 뻔한 키워드 대신, 고객이 다급할 때 실제로 포털 검색창에 타이핑하는 긴 문장이나 구체적 상황을 그대로 뽑아내도록 지시했습니다.
- 예: `식당 미성년자 주류 판매 영업정지 구제 방법`
- 예: `외국인 E-7 비자 이직 동의서 필수 여부`

### 2. 고객의 구매 여정(Customer Journey) 고려
단순히 정보만 찾는 키워드만 나오는 것을 방지하기 위해, AI가 10개의 키워드를 구성할 때 **인지(정보 탐색형) -> 고려(문제 해결형) -> 결정(전환형)** 의 단계별 키워드를 골고루 섞어주도록 프롬프트를 고도화했습니다.
- 블로그 전문성을 높이는 **정보성 글**과 실제 문의/수임으로 직결되는 **전환용 글**을 전략적으로 작성하실 수 있습니다.

### 3. Vercel 무중단 배포 및 에러 점검 완료
수정된 2개의 백엔드 파일(`src/actions/curation.ts`, `src/app/api/generate-clusters/route.ts`)은 `AGENTS.md` 제약사항에 따라 배포 전 타입스크립트 에러 점검(`tsc --noEmit`)을 100% 통과했습니다.
