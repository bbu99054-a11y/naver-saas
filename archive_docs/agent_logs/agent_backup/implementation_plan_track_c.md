# 트랙 C & 프리미엄 랜딩/로그인 페이지 구현 계획서

대표님, 드디어 서비스의 "첫인상(랜딩 페이지)"을 압도적으로 꾸미고, "마무리(네이버 발행)"를 가장 편하게 만들어 줄 단계에 왔습니다. 아래 두 가지 파트로 나누어 완벽하게 업그레이드하겠습니다.

## 📌 1. 랜딩 & 로그인 페이지 퀄리티 초격차 (마케팅 최적화)

현재 바로 대시보드로 넘어가는 밋밋한 구조를 버리고, **방문자가 보는 순간 결제하고 싶어지는 2026년형 프리미엄 SaaS 디자인**을 입힙니다.

### 🌟 랜딩 페이지 (`/page.tsx`)
- **히어로(Hero) 섹션**: 시선을 사로잡는 강력한 헤드라인 카피 ("단 3초 만에 터지는 블로그 포스팅, AI가 알아서 척척")와 부드러운 애니메이션 적용.
- **가치 입증(Features) 섹션**: '네이버 로컬 상권 분석', '실시간 팩트 체크(RAG)', '무료 AI 이미지 삽입' 등 우리가 만든 핵심 기능을 아름다운 카드 UI로 소개.
- **트렌디한 디자인 요소**: 애플이나 토스처럼 깔끔한 타이포그래피, 은은한 그라데이션, 글래스모피즘(투명 유리 효과)을 적극 활용.

### 🔐 로그인 페이지 (`/login/page.tsx`)
- 기존의 단순 폼 형태에서, 화면을 반으로 나누는 **스플릿 레이아웃(Split Screen)**으로 개편.
- 좌측: 화려한 3D 그래픽이나 서비스 가치 카피 노출 / 우측: 매우 직관적이고 깔끔한 로그인 폼.

## 📌 2. 트랙 C: 네이버 카페/블로그 완벽 호환 복사 툴 보완

현재의 단순 클립보드 복사 기능을 네이버 스마트에디터 ONE에 100% 최적화된 형태로 '초밀착' 시킵니다.

### 📋 클립보드 호환성 극대화 (서식 깨짐 방지)
- 단순 API 복사가 아니라 브라우저의 DOM `contentEditable` 트릭을 사용하여, 텍스트 굵기, 색상, 그리고 앞서 만든 **AI 삽입 이미지**까지 네이버 에디터에 붙여넣을 때 단 하나의 유실 없이 완벽하게 들어가도록 복사 로직을 전면 수정합니다.

### 🚀 원클릭 네이버 글쓰기 창 이동 (스마트 동선)
- 사용자가 [복사하기] 버튼을 누르는 순간, 클립보드에 내용이 저장됨과 **동시에 네이버 블로그 글쓰기 페이지가 새 탭으로 자동 실행**됩니다. 
- 사용자는 새 탭이 열리자마자 `Ctrl+V`만 누르면 모든 발행 준비가 끝납니다.
