# 🚀 [패치 완료] 원고 저장소 가로 스크롤 제거 및 상세 보기 자동 발행 버튼 탑재

## 1. 개요 및 주요 해결 내역
* **[ZONE-2] 원고 저장소 (`/dashboard/archive`) 화면 최적화**:
  - 기존: 테이블 너비 초과로 우측으로 드래그(가로 스크롤)해야만 관리 버튼이 보이고, 마우스를 올리지 않으면 [보기] 버튼이 숨겨져 있던 불편함
  - 수정: `table-fixed` 반응형 구조로 전면 리팩토링하여 어떤 해상도에서도 화면 내에 100% 쏙 들어오며, [열기] 버튼이 항상 시각적으로 깔끔하게 노출되도록 개선.
* **[ZONE-2] 원고 상세 보기 (`/dashboard/archive/[id]`) 내 [네이버 자동 발행] 버튼 탑재**:
  - 기존: [블로그 복사] 버튼만 존재하고 [네이버 자동 발행] 버튼이 누락되어 있던 문제
  - 수정: `AutoPublishBtn`을 우측 액션 툴바 최상단에 장착하여, 과거 저장된 모든 글도 AI 재생성 비용 없이(0원) 클릭 한 번으로 즉시 네이버 블로그에 자동 발행할 수 있도록 완성.
