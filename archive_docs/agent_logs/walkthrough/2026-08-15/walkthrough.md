## 💎 새롭게 장착된 8종 인포그래픽 카드 라이브러리

1. **[카드 1] 최상단 1:1 맞춤 썸네일 카드 (800x800)**
   - 모바일 세이프존 + 글 카테고리 뱃지 + 질문형 타이틀 + 브랜드 서명
2. **[카드 2] 3대 필수 요건 체크리스트 카드 (800x450)**
   - 체크박스 아이콘 + 요건별 세부 기준 3단계 박스
3. **[카드 3] Before vs After 비교 대비 카드 (800x450)**
   - 잘못 대처했을 때 (불리) vs 올바른 전문가 해결책 (유리) 2열 분할 비교
4. **[카드 4] 핵심 수치 & 감면율 대형 하이라이트 카드 (800x400)**
   - 대형 볼드 폰트로 절세액 / 공제금액 / 법정 기간 강조
5. **[카드 5] 3단계 실무 행동 로드맵 카드 (800x450)**
   - 화살표 1단계 ➔ 2단계 ➔ 3단계 행동 지침 프로세스
6. **[카드 6] 의뢰인 빈출 질문 & 전문가 팩트 해설 카드 (800x420)**
   - 의뢰인이 가장 오해하기 쉬운 질문(Q) + 전문가 명쾌 해설(A) 박스
7. **[카드 7] 골든타임 & 리스크 주의 경고 카드 (800x380)**
   - 법정 기한 만료 위험 및 과태료/가산세 패널티 주의 경고
8. **[카드 8] 오늘의 핵심 3줄 결론 요약 카드 (800x480)**
   - 결론부 직전, 바쁜 모바일 독자를 위한 3초 스캐닝 요약
9. **[카드 9] 하단 상담 유도 (CTA) & 오시는 길 배너 (800x480)**
   - 직통 대표번호 + 상세 주소 + 네이버 지도/예약 링크 통합

## 💎 글마다 달라지는 "탈-양산형 가변 작동 방식"

1. **글마다 다른 카드 조합 (3~6장 유동 배치):**
   - AI가 글의 주제(긴급 구제, 절세/상속, 테크/특허, 의료, 가사/이혼 등)와 길이에 맞춰 8종 중 가장 어울리는 카드를 2~4장 자율 선별하여 본문 설명 직후에 자연스럽게 배치합니다.
2. **2026 프리미엄 라이트 모드 테마 자동 조색:**
   - 네이버 블로그의 화이트 배경과 완벽하게 어우러지는 6대 컬러 테마(Classic Cream/Gold, Modern Ice Blue, Frosted Sage, Warm Oatmeal, Soft Lavender, Clean Modern Slate)로 화사하고 선명한 고대비 가독성을 보장합니다.
3. **소제목 중복 0% 달성:**
   - 검은색 챕터 바와 겹치던 문제를 해결하여, 소제목은 네이버 스마트블록 검색에 강력한 **'문장형 H2'**로 깨끗하게 단일화되었습니다.
4. **네이버 100% 실물 사진 인식 (2026 W3C 표준 클립보드 & 2x 레티나 캔버스 PNG 자동 변환):**
   - [블로그 복사] 클릭 시 0.1초 만에 2배수 초고화질 순수 PNG 사진(`data:image/png;base64,...`)으로 자동 변환되어, 네이버 에디터에 보안 경고 없이 5~6장의 사진으로 100% 정상 등록됩니다.

## 🧪 상세 테스트 방법 (Step-by-Step Test Guide)

1. **글쓰기 페이지 접속:**
   - 브라우저에서 `http://localhost:3000/dashboard/write` 로 이동합니다.
2. **새 원고 생성:**
   - 타겟 키워드(예: `송파구 문정동 음식점 창업 사업자등록 전 세금 감면 혜택`, `상속세 1주택자 공제 기준`) 입력 ➔ **[AI 블로그 생성하기]** 클릭.
3. **스마트에디터 미리보기 확인:**
   - ✅ **최상단 썸네일:** 화사한 웜 크림/골드 바탕에 볼드 딥 네이비 타이틀로 선명하게 표시.
   - ✅ **본문 중간 카드들:** 체크리스트, Before/After 비교표, 3단계 로드맵, 3줄 요약 등의 글씨가 **검은 화면 없이 화사한 라이트 배경 위에 100% 또렷하게 렌더링**되는지 확인.
   - ✅ **하단 배너:** 중복 글상자 없이 프리미엄 상담 배너로 깔끔하게 단일화.
4. **네이버 블로그 에디터 붙여넣기:**
   - 하단의 초록색 **[블로그 복사]** 버튼 클릭 (모든 카드가 2배수 초고화질 PNG 사진으로 0.1초 만에 자동 변환)
   - 네이버 스마트에디터 ONE에 `Ctrl + V`로 붙여넣기
   - **확인 결과:** `"허용되지 않은 이미지"` 보안 경고가 전혀 뜨지 않고, **5~6장의 고화질 사진이 네이버 서버에 정식 등록**됩니다!
