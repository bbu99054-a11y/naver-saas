# 본문 중간 시각 인포그래픽 카드 선별 수량 확대 (2~5장) 완료 보고

## 1. 개요 및 변경 사항
- **요청 사항**: 본문 중간 시각 인포그래픽 카드의 가변 선별 개수를 기존 `1~3장`에서 **`2~5장`**으로 확대 적용 요청.
- **적용 결과**: 
  - `[ZONE-6]` 백엔드 AI 생성 엔진 (`src/app/api/generate-seo/route.ts`)의 시각 카드 배치 규칙을 수정하여, 본문 중간에 주제별 최적의 인포그래픽 카드를 **2~5장** 자율 선별하도록 업그레이드했습니다.
  - 최상단 1:1 맞춤 썸네일(사진 1) + 최하단 1:1 상담 유도 배너(사진 9) 필수 2장을 포함하여, 글 전체에 들어가는 카드 이미지의 총 개수가 **총 4~7장**으로 한층 더 풍성하게 구성되도록 동기화했습니다.
