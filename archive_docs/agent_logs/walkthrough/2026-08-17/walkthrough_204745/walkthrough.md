# 전문직 맞춤 4대 톤앤매너 적용 및 프로필 설정 정리 완료 보고

## 🎯 작업 개요
* **내 정보 및 온보딩 정리**: '내 정보 및 RAG 지식베이스(`settings/profile`)'와 '온보딩(`onboarding`)' 화면에 남아있던 불필요한 기본 톤앤매너 입력란을 깔끔하게 제거하였습니다.
* **전문직 특화 4대 톤앤매너 적용**: 글쓰기 화면(`dashboard/write`)의 톤앤매너 드롭다운을 전문직(변호사, 세무사, 의사, 노무사, 감정평가사 등) 실무에 최적화된 4가지 문체로 교체하였습니다.
* **글쓰기 엔진 정밀 연동**: 글쓰기 엔진의 기존 작성 구조(CoT 팩트체크, 9종 시각 카드 디자인, 5대 후킹 제목, 스마트블록 스니펫 박스, 컴플라이언스 법률 가이드)는 100% 원형 그대로 보존하면서, 사용자가 선택한 4대 톤의 어조, 종결어미, 서론 공감/경고 방식, CTA 뉘앙스가 정확하게 반영되도록 `<tone_and_manner_guideline>` 섹션을 정밀 연동하였습니다.

### 2. [ZONE-6] 글쓰기 코어 엔진 프롬프트 정밀 연동
* **[글쓰기 API](file:///c:/workspace/naver_SaaS_Copy_For_USB/src/app/api/generate-seo/route.ts)**:
  * `getToneGuideline(tone)` 헬퍼 함수 구현 및 시스템 프롬프트 `<tone_and_manner_guideline>` 주입:
    * **신뢰형 전문가 칼럼**: 법리·판례·세법 근거 중심, 객관적 어조(`~에 해당합니다`, `~판단됩니다`), 전문성과 권위 입증.
    * **친절한 1:1 상담사**: 어려운 용어의 일상 비유 전환, 의뢰인의 불안에 깊이 공감하는 다정한 어조(`~하셔서 많이 놀라셨을 텐데요`, `쉽게 말해 ~라고 이해하시면 됩니다`).
    * **긴급 리스크 경고형**: 기한 경과/가산세/절차상 실책에 대한 단호한 경고 및 즉각적인 골든타임 행동 지침(Action Item) 제시.
    * **성공 사례 스토리텔링**: [초기 위기 ➔ 숨은 쟁점 발굴 ➔ 전략적 해결]로 이어지는 흥미진진한 1인칭 해결 서사.
  * **기존 작성 엔진 원형 100% 보존**: CoT 팩트체크, 9종 시각 카드, 스마트블록 스니펫 박스, 네이버 16px 본문 스타일, 5대 후킹 제목 프레임워크 모두 완벽 유지.
