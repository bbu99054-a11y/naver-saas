# 썸네일 제목 어절(단어) 단위 자연스러운 줄바꿈 구현 완료 보고서

## 📌 작업 개요
- **목표:** 대표 썸네일 제목 생성 시 단어가 중간에서 끊기지 않고 띄어쓰기(어절) 기준으로 깔끔하게 2줄 배치되도록 개선하고, 15자 이상 공백 없는 단어가 들어올 경우 카드 밖으로 튀어나가지 않게 글자 수 기준으로 안전하게 분할하는 Fallback 로직 추가.
- **원칙 준수:** 글쓰기 AI 엔진(LLM/프롬프트/SEO 생성 API)은 1줄도 수정하지 않고, 이미지 렌더링 템플릿(`procedural-generator.tsx`) 내부 조판 로직만 단독 수정.

## 🛠️ 수정 내용

### [procedural-generator.tsx](file:///c:/workspace/naver_SaaS_Copy_For_USB/src/lib/image-engine/procedural-generator.tsx)
1. **`formatThumbnailTitle` 헬퍼 함수 구현:**
   - **어절(단어) 분할 & 15자 Fallback:**
     - 띄어쓰기 기준으로 단어 토큰을 분리.
     - 단어 길이가 15자 이상일 경우 12~13자 단위로 안전하게 1차 강제 분할.
   - **황금비율 2줄 분할 알고리즘:**
     - 16~34자 내외의 표준 썸네일 제목은 윗줄과 아랫줄의 글자 수 차이(`|line1 - line2|`)가 최소화되는 최적의 어절 분기점을 찾아 2줄로 자연스럽게 배치.
   - **초장문(35자 초과) 3줄 균형 분할:**
     - 35자 초과 긴 제목은 최대 3줄로 균형 있게 분할.
   - **짧은 제목(15자 이하):**
     - 1줄 유지.
   - **명시적 줄바꿈(`\n`) 보존:**
     - 입력값에 이미 엔터(`\n`)가 포함된 경우 해당 줄바꿈 존중.

2. **4종 썸네일 레이아웃(`THUMB_A`, `THUMB_B`, `THUMB_C`, `THUMB_D`) 적용:**
   - 기존 통 텍스트(`{title}`) 렌더링에서 `titleLines.map(...)` 기반 개별 라인 Flex 렌더링으로 전면 개편.
   - 레이아웃 정렬(중앙 정렬 / 좌측 정렬)에 맞춘 `alignItems` 및 폰트 크기 동적 스케일링 연동.
